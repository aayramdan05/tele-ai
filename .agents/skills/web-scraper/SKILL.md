# Web Scraper Skill

Mengambil konten dari halaman web publik untuk riset, rangkuman, atau ekstraksi data.

## Panduan:
- Gunakan `curl -sL <url>` atau script Python sederhana dengan `urllib.request` atau `BeautifulSoup`.
- Bersihkan tag HTML yang tidak diperlukan untuk menghemat token dan menjaga kerapian teks.
