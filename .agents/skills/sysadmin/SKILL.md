# Sysadmin & DevOps Skill (Hermes DevOps Agent)

Kemampuan untuk memantau dan memelihara server VPS Linux Debian secara efisien.

## Perintah Utama:
- Cek performa server: `uptime`, `free -h`, `df -h`, `top -b -n 1 | head -n 20`
- Cek dan kelola PM2: `pm2 status`, `pm2 logs tele-ai-studio --lines 50`, `pm2 restart tele-ai-studio`
- Cek status jaringan & port: `ss -tulnp`, `curl -I localhost:3000`
