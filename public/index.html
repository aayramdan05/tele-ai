🎬 Facebook Reels Auto Clipper Pipeline

Format 16:9 Letterbox & 9:16 Vertikal

Untuk menghindari risiko pemblokiran 403, sistem ini menggunakan arsitektur hybrid:

1

Discovery & Download

Menggunakan yt-dlp di VPS secara lokal tanpa menyentuh Google API.

2

Transkripsi Subtitle

Menggunakan faster-whisper offline di server untuk akurasi timestamp per kata.

3

Kurasi Konten (Gemini)

HANYA 1x API CALL untuk menentukan 45 detik terbaik dan membuat Judul Hook.

4

Render FFmpeg

Memotong video, memberi padding bar atas-bawah, dan burn subtitle font tebal.

Format Video FB Reels:

Opsi 1: Rasio 16:9 Landscape dengan Top & Bottom Title 
ffmpeg -i input.mp4 -vf "pad=1920:1080:(ow-iw)/2:(oh-ih)/2:black,drawtext=text='JUDUL ATAS':fontcolor=yellow:fontsize=48:x=(w-text_w)/2:y=60" output.mp4
Opsi 2: Rasio 9:16 Vertikal (Full Reels) dengan Video di Tengah 
ffmpeg -i input.mp4 -vf "scale=1080:-1,pad=1080:1920:0:(1920-ih)/2:black,drawtext=text='HOOK VIRAL':fontsize=54:fontcolor=white:x=(w-text_w)/2:y=200" output_reels.mp4

Anda bisa langsung meminta agent via Telegram: "Jalankan scripts/clipper-helper.py untuk link video https://... jadikan reels 16:9 judul atas-bawah dan kirim videonya kesini"
